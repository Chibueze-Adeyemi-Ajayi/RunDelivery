🚗 Driver App

Simulate a driver application. Use this to emit location updates to the server manually or via auto-move mode.

👤 Customer App

Simulate a client application. Use this to join an Order ID room and listen for real-time driver location updates.

How to Test Real-Time Features

Step 1: Setup the Customer

1 Open the Customer App in a new tab.
2 Enter a unique Order ID (e.g., order_99) and click "Join Order Room".

Step 2: Setup the Driver

3 Open the Driver App in a separate window or tab.
4 Enter the SAME Order ID (order_99).
5 Click "Update Location" or "Start Auto-Move".

Step 3: Verification

Switch back to the Customer App tab. You should see the location coordinates appearing in the logs in real-time!
